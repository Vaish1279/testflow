UI testing

TestFlow is a structured software testing workspace for source code, applications, evidence, reports and controlled plan access.

Code Testing

Upload source code, choose a code-testing type and receive a focused report based on the uploaded files.

Application Testing

Upload an application ZIP, choose its HTML entry page, preview it in TestFlow and run application-focused checks.

Reports & History

Completed tests create private history records with formal reports, evidence, report viewing and download actions.

Plans & Access

Free, Premium and Pro control testing depth. Admin access unlocks all plans without payment and is protected by Supabase.

Product boundary

Current browser testing performs safe project-aware analysis. Server-side PHP/MySQL execution is not run directly in the main browser.

HOW IT WORKS

A test should leave evidence.

01

Account

Login is required before testing and history. Free access requires no payment.

02

Project input

Upload a ZIP or project folder. A project is not executed automatically.

03

Run a test

Select an allowed testing type and explicitly press Run test. That action creates the session.

04

Evidence + report

Results, evidence and a report are stored against the completed session.

PRODUCT PRINCIPLES

Simple to understand. Structured to grow.

01

One workspace

Code-level analysis and application/UI testing are planned as one connected testing workflow.

02

Evidence first

Findings should be supported by actions, logs, timing, screenshots or source evidence.

03

Controlled access

Free, Premium and Pro are feature plans. Admin access is controlled by the database role.
